# V4 Campaign and Pre-Engineering Baseline Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Establish `hvs-extraction-v4` as the only active campaign without creating a V4 gold snapshot, then run and seal one no-gold Method B/Core pre-engineering dev baseline.

**Architecture:** V4 mechanically inherits V3's exact public sampling bytes and therefore preserves the 50-paper order and fixed 10-dev/40-test split. The external private repository selected by `STELLA_GOLD_DIR` remains the single canonical gold store; each campaign may later receive only a hash-only integrity manifest generated by a separate gold-authorized task. Extraction uses the active campaign registry, a run-owned empty roster cache, Method B with `core_prov`, and the existing fail-closed audit/seal path.

**Tech Stack:** Python 3, YAML workflow contracts, deterministic JSON builders, `unittest`, tmux/caffeinate, OpenAI-compatible LLM transport.
